# Brief 01 — "Offload"

## What the agent does

Offload is an iMessage agent that sells your stuff on resale marketplaces for
you. You text it a photo of the thing; it writes the listing, prices it, fields
buyer messages, haggles, and hands you a shipping label + payout. The user
never touches the marketplace app and never argues with a stranger.

Evidence plausibility: "sell-my-stuff concierge" is a real category — Flyp and
Sella sell your clothes/goods via managed listings, Facebook Marketplace buyers
already negotiate inside chat threads, and agent-in-iMessage products (Poke,
Rene, Muse/Photon in this library) establish the delivery surface. Fictional
product, plausible company.

## The one promise

**Text it a photo. It handles the haggling.**

## Audience

Group-chat-native people (20s–30s, urban) with a closet/garage of stuff they'd
sell if it weren't for the worst part: the strangers, the lowballs, the "is
this still available" purgatory. They already live in iMessage; the product
meets them there.

## Tone

Dry comedy. The agent is a *professional* — unbothered by lowballs, slightly
smug, competent. Not wacky. The joke is that it enjoys haggling so you never
have to.

## Why this isn't a library film

The six references cover messaging infrastructure (Photon), agent-in-group-chat
delegation (Muse/danieltian), mini-app API (Photon Mini), dinner booking (Poke),
platform vignettes (Linq), and memory/companionship (Rene). None is
commerce/selling, none involves a negotiation, and none uses a *second
conversation thread* as a dramatic device.

## Constraints for the film

- Must read as an edited launch film, not a demo walkthrough.
- The agent drives; the user only initiates + confirms.
- Money beats must land as satisfying physical events (stamp, cha-ching
  equivalent — within iMessage grammar: a card, a ✓, a cash bubble).
