# Brief 02 — "Layover" (generality test)

## The product

A fictional iMessage agent that watches your flights. When your connection
breaks, it doesn't wait to be asked — it texts first, holds a seat, and you
confirm inside the same message card. Nothing downloads; nothing opens in
Safari.

## One promise

**"Rebooked before you reach the counter."**

## Why this brief tests generality

Film-01's structure was *arrival-driven*: a stack that grows — send, receipts,
cutaway, return, payoff. The motion signature was new things entering.

Brief-02 deliberately inverts it: the interesting motion is **one object that
mutates in place**. A single rebook card lives in the thread and changes state
four times (finding → options → holding → confirmed) while the conversation
around it barely moves. Time passes via a clock chip, not new arrivals. If the
skill secretly only knows how to choreograph "growing stacks," this brief
breaks it.

Secondary differences: proactive agent (it speaks first — film-01's agent only
responded), time-montage inside one shot, and a card whose *content* is the
character.

## Audience

People who have watched a departure board flip red.
