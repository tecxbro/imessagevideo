# Attempts ledger

One subdirectory per preserved attempt:

- `baseline/` — trial leg, skill @ c49482a (reserved; fills at trial time)
- `revised/` — trial leg, revised skill (reserved; fills at trial time)
- `<worktree>-<slug>/` — notable builder attempts (first renders,
  consequential fixes) spotted during reconnaissance

Each subdir carries an `attempt-ledger.md` (timestamps, command/purpose/
outcome, kept-or-discarded) plus small copied artifacts. Large artifacts
are ledgered in `observations/preserved/LEDGER.md` by path+hash instead.
