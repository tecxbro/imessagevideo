- **Before.** The chess motif appeared early. At 28.85 it returns following a different product example, so the audience has a board it recognizes and a game it saw start.

- **After.** The viewer can infer the earlier game reached a playable result. The measured hold makes time to register it before attention has to move elsewhere.
- **Intent guess.** The callback closes a loop and makes the board read as an activity that finished.
- **Alternative.** Cut to the next game on the winning movement. The reel gains speed and loses time for the first result to be read.
- **Change for Direction.** Reserve time for the resolved state to register at delivery size, and measure that hold after editing and encoding. In the Keiki cut the audience should register what appeared onstage before brand information takes over.
