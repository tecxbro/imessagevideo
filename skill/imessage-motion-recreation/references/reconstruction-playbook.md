# Measured iMessage motion recreation

Use actual downloaded reference video as evidence. The target is the supplied animation's composition and timing. Never describe a capability test, generic approximation, copied source video, or unmeasured render as a one-to-one recreation.

## Work products

Maintain one directory per reference containing the original source, provenance metadata, frame inventory, measured scene manifest, extracted asset inventory, and an append-only execution log. Keep render engine source, output MP4s, comparison reports, and capability status separately. A method is available only after a real render succeeds.

This skill was developed against six references. Their observed scenes, access methods, failures and corrections are recorded in [the execution ledger](execution-ledger.md). The project beside this package contains the detailed per-agent logs. Observations are specific to this environment; probe availability again in a new environment.

## 1. Establish the reference

1. Read applicable AGENTS.md and environment instructions. Inspect selected environment readiness, actual network policy, existing packages, browser binaries and fonts. Preserve supplied proxy variables and TLS verification.
2. Resolve the exact URL and media. Prefer an official public video source or connected capability. X public syndication or public metadata may expose official CDN variants; LinkedIn public VideoObject data may expose contentUrl. A launch gallery may have og:video metadata. Record the original page and resolved media URL without claiming platform authorship has changed.
3. Preserve the raw metadata and source file. Use ffprobe to record width, height, rational frame rate, frame count, video duration, container duration and audio. Use video frames to set reconstruction duration. Container/audio tails can be longer.
4. Extract labeled overview sheets, then full-resolution frames at each scene's start, moving midpoint and settled state. Automatic scene detection provides candidates; inspect them. Rapid camera movement can trigger false cuts.
5. Inventory every scene's exact copy, line wrapping, geometry, colors, icons, image assets, camera framing, reveal order, transition boundaries and easing. Mark inferred values and unknowns explicitly.
6. Exclude live action only when requested or allowed. Record source-to-output time mappings for retained segments. Preserve aspect ratio and fractional cadence.

## 2. Separate design from camera

Rebuild editable text, message bubble shapes and tails, controls, sheets, menu rows, phone screens, dividers and typography. Keep phone hardware, internal interface state and camera pan/zoom in separate nested groups. Camera motion must not be approximated by changing every child's coordinates independently.

Static raster crops are appropriate for genuine raster assets: photographs, Memoji, map artwork, textured brand icons, hardware reflections or rich-link thumbnails. Static product screenshots and rich-card interiors may also be declared raster artwork when this materially improves reference fidelity; explicitly disclose that internal bitmap text is not individually editable. Preserve independent card/screen boundaries, editable outer layout, native conversation text and camera motion. Record crop rectangle, source frame/time and purpose. Whole-frame playback or a source-video layer is a reference preview, never a reconstruction.

Use a verified font binary where available and allowed. A family that resembles SF Pro is a hypothesis until glyph dimensions match. Record fallback family, weights and resulting width differences. Check missing emoji glyphs in the actual rendering environment.

Match UI and display faces independently. In one lunch message, SF Pro Display matched glyph height but produced a 257 px line where the reference was 286 px; SF Pro Text at the measured size produced 286 px. Measure actual ink bounds as well as text advance. Scaling a wrong family can hide width error while leaving glyph shapes wrong.

When a verified font still cannot match a held caption, source-derived glyph outlines are a useful explicit tradeoff. Keep the semantic copy, exact source frame, tracing bounds and provenance. Outlines are vector geometry, not live editable text. Fit individual glyph poses when animation changes kerning; scaling an entire word cannot reproduce changing relative spacing.

When tracking repeated bubbles/cards, constrain matches by row, ordering, expected scale and plausible displacement, not only appearance score. Similar neighboring bubbles caused false low-error matches and row jumps in the Photon wall pass. Keep a verified base-frame anchor and reject outliers before fitting motion. Use exact source frame indices for fractional frame rates; fps-filter bin centers are diagnostic samples, not certified event times.

## 3. Author a deterministic measured scene

Use the project's shared/scene-schema.json and shared/SCHEMA.md. Coordinates are source pixels; time is output seconds. Each layer has a stable ID, semantic purpose, visible interval and editable properties. Numeric transform and opacity keyframes are measured at actual source frames. Record source mapping and uncertainties in source.notes.

Use one scene manifest across compatible methods so engine differences can be isolated from design differences. Unsupported properties must produce an explicit capability failure, not silently disappear. Avoid unnecessary renderer-specific redesigns.

For an authorized multi-agent run, give each reference or disjoint frame interval one owner. Keep shared render engines under a single owner. Contributors release immutable helpers with explicit layer IDs, inclusive native frame ranges, asset hashes, native source checks and outside-range proofs. Merge accepted helpers into one immutable canonical scene, then give that exact file/hash to every method. A renderer-parity reviewer must also inspect the actual source; agreement between methods cannot validate the shared measurements.

## 4. Render using real methods

- **Remotion:** React Composition with useCurrentFrame, deterministic SVG or native elements, frame-by-frame capture. Use lossless intermediate PNGs and a controlled encoder.
- **GSAP:** Build a paused timeline, seek to frame/fps exactly, update native elements, capture with Chromium/Playwright, then encode.
- **Figma Motion:** Read the installed Figma use, design, creation and motion skills before calls. Resolve destination, create a file/session, inspect its structure, test the animation API, then create editable layers and measured keyframes. Export the owning top-level frame. A screenshot proves only resting composition. If the motion API returns unsupported, stop that branch once and record it.
- **HTML/SVG:** Evaluate explicit frame time into editable vectors and typography, capture frames and encode.
- **Pillow + FFmpeg:** Draw source-pixel geometry and typography, supersample when needed, and pipe deterministic raw frames to FFmpeg. Resolve font paths explicitly. Do not ignore unsupported group clipping, blur or tracking.
  Retain a base sampling factor and explicit per-frame overrides when only a difficult transition needs denser sampling. This run's [sampling plan](render-overrides.json) is a measured example, not a preset for a new reference. Compare actual source pixels as well as renderer parity before accepting an override.
- **Motion Canvas:** Use genuine Scene2D nodes and deterministic native canvas frames. A previous browser failure does not establish current unavailability; run a small actual test and diagnose the error.

Do not use generated video for exact UI text, typography or reproducible geometry. If explicitly authorized, generation may fill an asset gap. The originating user's limit was no more than two retries per generated clip; retain the same bound when using this workflow unless they change it. No generated clips were required for the initial capability tests.

## 5. Compare before claiming fidelity

1. Compare aligned reference/candidate frames at the same native dimensions and exact source/output times. Use the time map for omitted segments.
2. Inspect reference, render and amplified difference side by side. Check text widths/baselines, bubble tails/corners, phone geometry, clipping, colors, transition phase and motion blur.
3. Record global MAE/RMSE/PSNR/SSIM and foreground error separately. White backgrounds can hide missing UI in global scores. These measurements diagnose differences; they are not a single perfection percentage.
   Fit geometry before replacing artwork. In the Mini Apps food-card test, richer internal artwork barely changed error because the whole card was about 22–24 pixels too high. Asset quality could not repair the camera/layout error; the next correction measured multiple blue-bubble anchors first.
4. Check every scene at start/mid/settle and dense frames around transitions. Before closing a high-fidelity recreation, scan **every aligned native frame**, rank separated error peaks, and visually inspect those peaks with foreground comparisons. Good held samples can conceal large errors between them: Linq's sparse final samples had global MAE about 2.4, while an every-frame scan found mean 14.5 and a peak over 144 from missing transition states and mistimed camera motion. Sampled agreement proves only sampled agreement.
5. Keep renderer parity and reference fidelity separate. Identical engine outputs can all be wrong relative to the reference.
   Keep explicit known-issue holds alongside numerical checks. A one-pixel baseline regression can pass an aggregate SSIM threshold, and a current scene hash cannot prove every cached frame contains its artwork. Final quality and packaging must reject unresolved holds; close each with actual capture/verification evidence or a precise, evidenced limitation.
   A pixel-identical outside control proves preservation, not source accuracy. Measure its own source error before calling it strong. Rene's preserved616 still had native error6.105, so the same portrait investigation continued there; Linq's initially protected1338 contained a genuinely missing title line.
   Retain lossless frame caches until quality review finishes. Browser renderer `--frames-dir DIR --start-frame FIRST --end-frame LAST` can replace a known changed inclusive range and re-encode only after confirming the complete cache exists. Enumerate every changed interval before a partial render; unrendered ranges must still correspond to the prior approved scene. Use atomic PNG replacement when cached frames share hardlinks.
6. Verify final fps, frame count, duration, dimensions, source mapping, editability and declared audio treatment. If audio was omitted, say so.

## 6. Diagnose, then retry

Before any retry, append: attempted action, observed result/error, evidence, identified or hypothesized cause, proposed targeted correction, and what the next check will establish. Do not repeat an unchanged failed operation.

Useful diagnoses observed during this project:

- A Playwright cache path existed as a string but its executable was absent. The installed /usr/bin/chromium worked.
- Motion Canvas Node requires an argument object. `new Node({})` corrected a constructor error; the browser was available.
- Remotion's default JPEG capture and encoder color conversion introduced differences. PNG capture and a shared explicit Rec.709 encoder isolated scene fidelity from encoding.
- An MP4 read before its encoder finished had no moov metadata. Waiting for completion corrected the read ordering; rerendering was unnecessary.
- Public media servers can require a normal browser User-Agent and the embedding page's Referer. Distinguish a remote 403 from a policy denial and preserve the response evidence.
- An unanswered Figma account call does not prove Motion API support or lack of support. Record access as unverified and use a bounded diagnostic.
- Valid font files can still be the wrong family. Compare distinctive glyphs and fit the actual reference; square versus circular i-dots exposed one wrong initial SF assumption in this project.
- Multi-megabyte font data inside a regenerated SVG can be parsed again every frame. Load font CSS once, explicitly wait for fonts, and subset used glyphs. Verify before/after native PNGs so performance work cannot conceal a visual change.
- An image with an alpha channel can be completely invisible. Decode every used asset, record its visible bounding box, and reject empty alpha. A filename, successful import or nonzero byte count does not establish visible artwork.
- Test transparent artwork over a contrasting underlay. Motion Canvas image nodes once inherited an opaque black default fill, destroying the screen cutout. Cross-engine parity is insufficient if both paths share a faulty assumption.
- Blur translucent images in premultiplied color space, then unpremultiply. Straight-RGBA filtering produced an impossible dark halo around a white composer. In a scene graph, apply blur in the layer's local composite coordinates so parent scaling also scales the blur radius.
- Composite a shadow and opaque content before applying their shared fade. Applying one Canvas draw's globalAlpha to the image and shadow let the shadow show through a fading card. A native inner shadow/content node at opacity1 with a separate outer fade corrected the neutral expected RGB and reduced actual board259 renderer error4.225→.629. Audit exact affected lifecycles and retain original capture fingerprints before refreshing caches.
  When that same component also needs local Gaussian blur, apply the shadow in the same local coordinates before the blur and outer fade. Converting a world-scaled shadow again inside the local Gaussian composite double-scaled it and regressed an actual combined-effect control. The corrected local shadow/blur composition improved that control while retaining all previously accepted opaque and dynamic-path frames.
- Viewport clipping is not resizing. Preserve a card's full scale and anchor its visible edge; squeezing the full artwork into the clipped bounding box deforms it.
- A text/caption string is not a unique tracking identity. Repeated captions require spatial trajectory, row and appearance constraints. Matching only y also misassociated different bottom-clipped cards.
- Preserve semantic identity when visible words merge or fade. Assigning remaining connected components to the first N labels turned incoming words into outgoing ones, delayed a logo reveal, and relabeled a fading CTA suffix. Use stable word/glyph identities and measured birth/death times; inspect the complete handoff, including a final faint word after its neighbor disappears.
- Match discrete app states as well as motion. A chess pawn's earlier hover material lacked the post-move undo control and retained a highlight on the wrong square. Recover the correct bounded UI state independently of the moving piece, measure the complete trajectory through settle, and preserve the board camera. One early matching texture does not establish later state accuracy.
- Inspect the first native frame and the first typed character. A composer begins with a placeholder/microphone before its send control appears; showing the final control from frame0 or guessing the typing cadence is a lifecycle error even when the held draft looks accurate. Keep entry, semantic text, caret, placeholder and send-control births independently measured.
- Separate the screen surface, header, metal hardware and conversation camera when the source moves them independently. Rene's screen stays opaque while its rim reveals from top to bottom; fitting one scalar opacity exposed background email cards through the screen. Source-specific optical hardware or card-deformation pose textures can be retained as strictly bounded original artwork, with their bitmap limitation and masking evidence declared. Never replace the complete frame with that artwork.
- Normalize image measurements to the layer's declared dimensions before deriving a camera. A mascot file was 175×194 pixels but its layer was declared 72×79; using intrinsic template dimensions gave a false negative y-translation of hundreds of pixels.
- Reject component tracks that change identity. An island detector selected an entering phone body whose box ended at the ROI boundary, producing a scale jump from 2.68 to 8.17. Require aspect, expected location and temporal continuity. When inferring offscreen cards, use an identified matching card's true scale; a median that includes unrelated UI fragments is not a valid camera estimate.
- Recheck source RGB differences before assuming repeated frames. Photon had actual fast nonlinear scroll on supposedly duplicated frames. Renderer parity showed that the sparse source trajectory, not browser timing, caused the mismatch.
- Use exact frame indices in checkpoint tools (`--frames 420,421`) so decimal rounding cannot choose the preceding discrete pose. After a scoped patch, prove evaluated markup unchanged at every frame outside its declared ranges with `scripts/verification/prove_scene_scope.mjs`; then compare native rendered pixels inside those ranges.
- For native peak reports, `compare.py --batch-native --segments PEAKS.json --times 0` can decode the selected frame indices once per video. It rejects non-native timestamps. Eight actual source checks, including fractional-cadence Poke frames, matched the original extraction pixel-for-pixel. Keep that parity evidence when changing extraction; faster review must not change the chosen pictures.
  Container duration rounding can make average and nominal rates differ slightly: the RENE source reports29.999982 average for nominal30fps. The helper retains both rates and accepts an exact nominal time only within1ppm and when both rates select the same integer frame. Eight actual RENE frames matched the average-rate diagnostic exactly; arbitrary off-grid times remain rejected. Long consecutive selections are coalesced into ranges to avoid FFmpeg expression-parser capacity limits.
- Fit material dimming separately from overall fade when bright and dark parts move in opposite directions. Mini's exiting phone screen darkened while its rim lightened. A single opacity could not explain that evidence; an independent black material mask plus parent opacity reproduced it using one static bounded phone asset and numeric motion.
- A fading content group does not guarantee an opaque backdrop. Keep required white or black mattes independent when fading content would expose the wrong preceding scene.
- Inspect exact entrance frames. One number-field candidate matched its held state but displayed a full lattice where the source had only one central cue and staggered outer rings.
- Use source frame indices as the timing authority. FPS-filter contact sheets can be shifted by one frame. Snap floating-point boundaries only when they are numerically indistinguishable from an intended integer frame.
- Distinguish CPU count from CPU quota. Excess concurrent browsers and FFmpeg workers caused timeouts on a four-core quota. Bound encoding threads and queue work; preserve caches rather than repeating successful captures.
- A transport byte limit does not bound native scene-graph cost. One Motion Canvas chunk contained thousands of tiny material rectangles; a single frame still needed2,716 authored nodes. Check actual node/wrapper counts, CPU and heap before declaring a stall. An initial full-timeline replay hypothesis was rejected after reading the real renderFrame call path; the original production render eventually completed without a retry or engine change. Keep performance prototypes separate from proven production fixes.
- Bound browser transport for dense vector scenes by pruning only inactive declared lifecycles at the exact requested times, then prove evaluated SVG identical at every captured frame. Keep the authored JSON/hash as the source of truth. Synchronize both Remotion inputProps and the selected Composition's resolved props per chunk; changing inputProps alone once left later chunks blank. An actual multi-chunk frame test caught that before any production Remotion export.
- Reuse one explicitly owned Remotion browser across transport chunks through documented openBrowser/puppeteerInstance options. Repeated chunk launches once failed after successful captures with a25-second startup timeout. Confirm actual multi-chunk PNG parity before retrying, and close the owned browser in finally.
- A foreground panel's top leaving the viewport does not mean its entire backplane is hidden. Measure exposed side and bottom regions independently, preserve the required display matte, and keep world artwork outside UI masks. Check occlusion masks against independently owned food/cards so a background correction cannot duplicate or erase them.
- Register a moving app/card by independent surfaces when the source requires it. A capsule container, inner logo/label and right control can have different tilts; a menu thumbnail can scale independently and overhang its white paper row. Strong feature matches on one part do not prove the whole group is rigid. Check a clean app edge when a win badge or incoming app biases texture NCC.
- A double edge can be shutter exposure rather than a simple position error. Fit exposure support from actual white-card and ink extents; constrain native samples to that support. Unconstrained small weights created false distant ghosts. Keep an accurate material field fixed when correcting only the exposed content.
- Prefer measured native blur/opacity on one accepted static component for a continuous optical fade. Coarsely quantized per-frame contours introduced visible blur bands and degraded an already accurate held frame. Trace separate native poses when typing, kerning or genuine geometry changes require them.
- Check faint overlapping contours at the actual compositing precision. Forty-eight small-opacity layers intended to produce gray231 produced247 in both Chromium and native Motion Canvas. A single-alpha control and absolute gray231 material both produced231. Opaque tone bands can repair this quantization when the underlying surface is known; inspect their antialiased edges before replacing an already stronger optical model.
- Inspect a static asset's complete UV extent before reusing it earlier in a transition. A card cropped while offscreen lacked material exposed a few frames earlier; transforming the clipped crop could not restore it. Recover the same component's missing material or use a bounded continuation, preserving its camera and identity.
- Resolve a partial render's cache from its actual completion sidecar. A familiar directory name is insufficient: one HTML baseline lived in a retained temporary directory. Seed an exact retained cache before replacing changed ranges, and require every expected frame before encoding.
- Inspect isolated renderer outliers even when aggregate SSIM is high. A Linq Remotion cache contained one white horizontal truncation at625; a fresh capture of the exact frozen scene was pixel-identical to GSAP. Refreshing that cached state corrected the artifact without changing scene geometry. Its original cause was not established and must not be presented as a proven decoder or renderer bug.
- Reproduce a suspected cache defect with a fresh render before naming its cause. Mini's Pillow frames436–494 contained flat-color rectangles even in a fresh same-process capture. A clip-wrapper scale10000 canceled a child scale near.000076 only after the rasterizer had reduced the intermediate to1×1. Condition the internal coordinates before rasterization, prove unaffected frames identical, and apply supersampling only to the exact affected union.
- Measure inline leading and transformed font shaping separately. Motion Canvas text initially sat 4–6 pixels too high. Removing measured DOM leading fixes that error, but SVG also shapes fonts at the world transform's RMS scale, sqrt((a²+b²+c²+d²)/2). Drawing the native Canvas font at that size with a compensating inverse transform reproduces the shaping; an ascent offset alone does not. Test anchors, spacing, stroke, multiline, fallback emoji, blur and same-process animated ancestors. A correct glyph baseline does not automatically validate an independently drawn underline.
- Compare actual shaping policies as well as computed style names. SVG and Canvas both reported automatic kerning, yet two Canvas subtitle runs were 3–4 pixels wider. Explicit normal kerning before both width calculations matched SVG and the DOM layout. Verify all affected styles before changing a global default; retain previous captures and audit zero-effect contexts.
- Fit dark material at actual compositing precision. A continuous alpha fit regressed24 Linq states because Chromium rounds alpha to8bits and floors premultiplied dark channels. Measure the native byte mapping, preserve the original on ties, and check every changed native state before promoting the correction.
- Preserve both actors during an avatar crossfade. A selector that jumps between rows cannot represent simultaneously visible outgoing and incoming portraits. Fit both source alpha lifecycles, keep full uncensored artwork dimensions and inspect guards beyond the transition.
- Match high-resolution component detail to the actual zoom. Enlarging a small rich-card raster by3.77 can blur text even when its camera is right. A bounded, source-provenanced static UI detail layer can restore the same component's ink without copying phone hardware or other planes. Validate its complete visible lifecycle: an initial material improved the peak but regressed a later pose, so it was rejected before a multi-pose correction was accepted.
- Verify color transport in the actual player as well as FFmpeg extraction. Gray253 became252 in one limited-range extraction while Chrome displayed253. Plain full-range with incomplete color tags instead displayed255 in Chrome. Coherent full-range BT.709 primaries/transfer/matrix tags corrected the measured case; range alone was insufficient. Preserve capture fingerprints and hash retained PNGs before/after any encode-only correction. Player drops under CPU contention and picture corruption are separate observations.
- Use immutable scene snapshots and completion sidecars. Write output to a temporary MP4, atomically replace it after encoding, then publish metadata. Remove old completion metadata before replacing a master.

### Local event-onset acceptance

Build the shot plan's event list early with `python scripts/verification/event_onsets.py scan SOURCE.mp4 --out events.json`. Compare every export before acceptance with `python scripts/verification/event_onsets.py compare SOURCE.mp4 EXPORT.mp4 --events events.json --tolerance 2 --out report.json`. Supply `--frame-map` for changed timelines and `--roi-events` for important events the automatic scan misses. Review failures and candidate-only events against native frames; broad camera motion and repeated controls can produce heuristic false matches. Full-frame MAE peaks alone do not validate event timing.

Poke's small restaurant selection was twelve frames late despite unremarkable full-frame error. Its blue/check overlays retained `start: 21.5`; the separate trial moves both to native frame633 and the automatically discovered event changes from645 (+12, late) to633 (0, pass). Other review flags remain; frozen films and audio are unchanged. See [the trial and reports](../../../trials/poke-selection-onset/).

## 7. Deliver concrete artifacts and truthful status

Provide the videos, editable scenes/source, review gallery, comparison data and this skill. Distinguish completed methods, unavailable methods, and unverified access. State material fidelity gaps clearly. Never label an approximate rebuild 100% perfect because it renders successfully or because the user requested perfection.

Keep the execution log current while work happens. Store transferable rules here and detailed chronological evidence in references/execution-ledger.md; do not turn unverified assumptions into instructions.

For portable delivery, validate actual file types and hashes rather than extensions. One extracted License.rtf was a 219 MB gzip payload alias; the genuine official XAR license member was 12,517 bytes and was restored with verified archive-member hashes. Protect original archives and installed runtimes during storage cleanup. A temporary hardlink staging tree can avoid duplicating immutable assets, but generated state/manifests must be written atomically so staging never mutates the working project. A ZIP contains independent bytes even when its staging tree used hardlinks.

Superseded JSON histories may be stored as verified gzip archives. Restore a needed history with `gzip -dc history.json.gz > history.json` and check its recorded decompressed SHA before reuse. Keep current canonical scenes and active inputs directly available.

For public viewing and broken local review previews, follow `references/public-gallery-distribution.md`. Publish the complete media hierarchy with native inline video controls and direct MP4 fallbacks; verify unauthenticated byte-range delivery separately from browser playback. Record any hosting byte-limit failure before retrying in bounded source batches.
