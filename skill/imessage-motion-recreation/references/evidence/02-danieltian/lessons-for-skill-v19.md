# Source 02 lessons for the reusable recreation skill

1. **Track every simultaneous instance.** A per-frame selector that returns only the strongest same-logo/photo detection silently loses crossfades. Source 02 needed old and incoming Muse avatars at three row transitions. Keep the selected actor, correct only measured opacity, and add complementary instances with independent poses. A white wipe hides the alpha cause and can cover neighboring artwork.
2. **Keep identity and geometry separate from color components.** A white glyph can divide a pink logo into multiple islands. Native frames 1021/1022 fit the tiny internal island, halving two Airbnb badges. Use an identity-constrained search and the full outer silhouette; do not maximize an unconstrained bbox or select a closer central fragment. Source frame 565 similarly confused Lyft with Airbnb and treated a search-window crop as the actor boundary.
3. **Viewport censoring is not object size.** Green entry, food at 363, heart at 367+, and incoming Resy at 701 were clipped. Fit the complete authentic asset from uncensored support or a stable camera relation; render its full dimensions, then let the viewport/native iris clip it. Full-template NCC failure at an edge does not establish absence.
4. **Measure alpha in the calibrated renderer’s pixel space.** Fit contrast against the actual paper color and original art; keep geometry separate. Source-effective contrast may differ slightly from an assumed design alpha because of source encoding. Existing source 02 cameras were preserved while selected-avatar opacity was repaired. Add immediate native before/after guards so a new fade key cannot interpolate backward across accepted seconds.
5. **Bracket true low-alpha lifetimes.** Test original-art support at the proposed guard frames. Do not fabricate ghosts from compression blocks. Source frames 680/705 had weak noisy NCC/effective alpha ~0.001, and even best tiny projections worsened L1; retain those stronger original states. Record the counts, contrast view and rejected fit.
6. **Partial ink width is not whole-sentence scale.** The original reasoning implementation compressed a complete sharp sentence to a partial visible width, causing premature legibility. Dense semantic glyph contours reproduced actual partial/blurred copy and the shrinking plan inside the search iris. Native gray tone contours remain editable outlines, not live-font text; label that limitation and keep semantic copy metadata.
7. **Quantization matters.** Many tiny alpha layers failed a physical neutral-tone fixture. Opaque nested gray contours preserved the intended source tones. Closed-contour simplification at 0.08 native pixel tolerance reduced15.19M → 6.66M vertices without dropping semantic holes; validate the actual renderer after any simplification.
8. **Diagnose large-scene transport before retrying.** A100MB+ argument can exhaust browser transfer/resources even when the native scene is valid. Prune only provably inactive lifecycle branches, split transport into bounded chunks, preserve absolute source time and the full authored SHA, and prove full/pruned SVG states at every requested frame. Remotion must select a fresh composition per chunk; retaining first-chunk props made later chunks blank in a controlled test. Native MotionCanvas must still draw genuine Scene2D canvas nodes, not a screenshot/SVG shortcut.
9. **Keep source and renderer provenance distinct.** Retained frames can combine an old engine’s proven-compatible capture with new source intervals. Preserve original engineSHA in history; never relabel unchanged PNGs as newly captured. A same-adapter pixel-parity test validates a renderer change, not source fidelity.
10. **Use a complete quality loop.** Finish the full duration, freeze one canonical scene, capture aligned native images, inspect all encoded-frame error peaks and literal states, diagnose, then retry only the supported interval. Source 02 has 1,360 native frames. Final 19 changes 12 avatar states against 18; exact cumulative 379 against actual 13 is a hash-bound proof, not a quality percentage. Repeated headline previews would not reveal the missing interior avatars or late provider shrink.
11. **Bind encodes and reports.** Use the final coherent PC709 profile before the source scan. Native PNGs are the lossless source of truth; compare decoded RGB and test actual browser playback for color-range/matrix changes. Source frames 357/477 contain real paper/chroma coding artifacts absent neighboring frames; distinguish these from font/camera errors and avoid reproducing the entire encoded frame as a texture.
12. **Archive with one owner.** Write to a unique temporary gzip, verify the decompressed SHA against the raw input, atomically publish, and only then unlink the superseded raw JSON. Parallel writers collided once; verification rejected the archive while the original survived. Preserve current snapshots, assets, caches and proofs. Historical gzip restores must attest the original decompressed SHA.
13. **Check agent state.** `send_message` does not restart a completed agent. Use an explicit follow-up task when a new bounded assignment is authorized, and confirm ownership before a shared-file mutation. The avatar follow-up would otherwise have waited on an idle owner.

Evidence and executable recipes are in `steps-rebuild.md`, `v17-refinement/`, `orb-exit-v18/`, `muse-continuation-v19/`, and the frozen final 19 scope proofs. No 100% or full-timeline visual-certification claim follows from these metrics; residual art/rim, glass, silhouette, sampling and source-coding differences remain explicitly qualified.
14. **Separate file equality from pixel equality.** PNG compression and container metadata can change bytes without changing RGB. Hash first for speed, then decode mismatches. The all1,360-frame Remotion/G19 comparison distinguished647compression-only differences from713tiny raster differences; meanRGBMAE.000302606 does not justify saying pixel-identical. Inspect worst regions and keep renderer parity distinct from source fidelity.
15. **Do not restart from an isolated background warning.** A Remotion page-focus timer raced a closed session while the producer still exited0 and every capture/encode/provenance check completed. Identify the exact API/callsite and inspect actual outputs before classifying a target-close message as a memory failure or retrying a valid full render.
