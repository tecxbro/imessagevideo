How to use the visuals
For exact recreation, the supplied film controls geometry and timing. For new direction, choose a motif by the promise and action, inspect its visual evidence, adapt the components, then write a shot plan. Do not copy starter timing and call it measured source motion.
This viewer exports code and cue data. The bundled real rendering engines create video. It does not export an editable Figma file or automatically make a complete film from the brief.
