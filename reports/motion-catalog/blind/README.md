## Decoded previews and final scenes

**Night Garden.** The default preview showed a shared horizontal rail under the Saltwater House business header and stationary action row. The replacement shows Miso Moon, The Citrus Bar, Ember Grill and Petal Sweets riding a single strip left through a fixed clipping window. Night Garden, the Hours and Get there buttons, the address and the stage headline stay fixed. The source-derived movement runs from about 1.17 s to 1.83 s inside a 3.4 s scene, so the middle stalls pass through quickly. [Default preview frames](frames/place-photo-strip.preview.png) · [Final video](night-garden/night-garden.mp4) · [Sampled frames](frames/night-garden.png) · [Editable config](night-garden/replacements.json) · [Generated scene](night-garden/night-garden.scene.json)

**Field Crew.** The default preview showed individual front cards moving across the stack while the conversation remained in place. The replacement leads with Cedar Bridge. Its first leftward exit promotes Blue Lookout, and the second promotes Rust Pass. Sunrise Basin remains layered behind Rust Pass after the second swipe. The Field Crew header, group member names, message bubble, attachment count and composer stay in place. [Default preview frames](frames/messages-attachment-stack.preview.png) · [Final video](field-crew/field-crew.mp4) · [Sampled frames](frames/field-crew.png) · [Editable config](field-crew/replacements.json) · [Generated scene](field-crew/field-crew.scene.json)

The two configs reference eight original local SVGs by relative path. The final videos are 960 × 540 H.264 at 30 fps. Every frame decoded without error, 102 frames for Night Garden and 114 for Field Crew. The largest mean absolute RGB difference from frame 0 was 58.4129/255 in the Night Garden photo window and 54.2159/255 in the Field Crew stack area. The corresponding maximums were 0.0535/255 for the Night Garden title, subtitle and controls crop and 0.0019/255 for the Field Crew composer. These decoded-pixel measurements accompany the visual review. [Verification output](frames/verification.json) · [Verification script](verify.py)

The first preview commands returned absolute paths while the preview files were still being generated by a separate contributor. Both catalog previews were decoded and visually opened offline after the files appeared, then the final custom exports were rerun. The early Field Crew draft showed a fading outgoing card. The updated catalog export shows the front card staying opaque as it crosses the left clipping edge. The trial exercised standalone authored scenes and two render configurations.

## Exact commands

Run from the checkout root. The Python executable and Cairo directory below were local to this run.

~~~sh
node skill/imessage-motion-recreation/director/cli.mjs motion --help
node skill/imessage-motion-recreation/director/cli.mjs motion search 'Let'\''s make a quick carousel for night market stalls. I want the pictures to glide sideways underneath Night Garden while the Hours and Get there buttons stay put.' > reports/motion-catalog/blind/search/A.json
node skill/imessage-motion-recreation/director/cli.mjs motion search 'In a group thread called Field Crew, someone sent a bunch of pictures. Let'\''s swipe the front one to the left to see the one behind it, then swipe again. Keep the composer exactly where it is.' > reports/motion-catalog/blind/search/B.json
node skill/imessage-motion-recreation/director/cli.mjs motion search 'Tap the inline preview and bring a full-size control panel up from below, darkening the conversation that is still visible behind.' > reports/motion-catalog/blind/search/C.json
node skill/imessage-motion-recreation/director/cli.mjs motion search 'A bunch of headshots come together around the words Everyone is here. The text gets smaller without leaving the center.' > reports/motion-catalog/blind/search/D.json
node skill/imessage-motion-recreation/director/cli.mjs motion search 'carousel' > reports/motion-catalog/blind/search/E.json
node skill/imessage-motion-recreation/director/cli.mjs motion show place-photo-strip
node skill/imessage-motion-recreation/director/cli.mjs motion show messages-attachment-stack
node skill/imessage-motion-recreation/director/cli.mjs motion preview place-photo-strip
node skill/imessage-motion-recreation/director/cli.mjs motion preview messages-attachment-stack
ffmpeg -hide_banner -v error -y -i skill/imessage-motion-recreation/director/motion-library/previews/place-photo-strip.mp4 -vf 'select=eq(n\,0)+eq(n\,44)+eq(n\,90),scale=480:270,tile=3x1' -frames:v 1 -update 1 reports/motion-catalog/blind/frames/place-photo-strip.preview.png
ffmpeg -hide_banner -v error -y -i skill/imessage-motion-recreation/director/motion-library/previews/messages-attachment-stack.mp4 -vf 'select=eq(n\,0)+eq(n\,42)+eq(n\,90),scale=480:270,tile=3x1' -frames:v 1 -update 1 reports/motion-catalog/blind/frames/messages-attachment-stack.preview.png
node skill/imessage-motion-recreation/director/cli.mjs motion scene place-photo-strip --config reports/motion-catalog/blind/night-garden/replacements.json --out reports/motion-catalog/blind/night-garden/scene.json
node skill/imessage-motion-recreation/director/cli.mjs motion scene messages-attachment-stack --config reports/motion-catalog/blind/field-crew/replacements.json --out reports/motion-catalog/blind/field-crew/scene.json
env DYLD_FALLBACK_LIBRARY_PATH=/opt/homebrew/opt/cairo/lib node skill/imessage-motion-recreation/director/cli.mjs motion render place-photo-strip --config reports/motion-catalog/blind/night-garden/replacements.json --python /tmp/imessage-catalog-render.VYDSgA/bin/python --out reports/motion-catalog/blind/night-garden/night-garden.mp4
env DYLD_FALLBACK_LIBRARY_PATH=/opt/homebrew/opt/cairo/lib node skill/imessage-motion-recreation/director/cli.mjs motion render messages-attachment-stack --config reports/motion-catalog/blind/field-crew/replacements.json --python /tmp/imessage-catalog-render.VYDSgA/bin/python --out reports/motion-catalog/blind/field-crew/field-crew.mp4
~~~
