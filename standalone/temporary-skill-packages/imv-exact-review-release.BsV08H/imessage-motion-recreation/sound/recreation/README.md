# Train options sound score

The plan scores Recreation’s exact `Train options` handoff from commit `f0d65672e022ff1c827bd12bf1470445b85196d5`. The playable examples and exact copies of the final and edited picture masters are under `review/imv-v3/sound/recreation/`.

The title and first question need space to read. Let the request make the first sound. Keep the opening of the picker tactile, keep the choice precise, and give the receipt two short notes that settle before its held text. Four charted quiet regions guard the title, request reading time, seat choice reading time and final receipt hold. The mix uses an effects bus. Each original sound has an independently adjustable full-length cue stem.

| Event | First pass frame | Final frame | Edited frame | Planned impact offset |
|---|---:|---:|---:|---:|
| Outgoing request | 30 | 30 | 30 | +6 ms |
| Picker handle appears | 56 | 56 | 56 | −16 ms |
| First seat check fills | 78 | 74 | 69 | +9 ms |
| Receipt appears | 89 | 89 | 89 | +14 ms |

The outgoing source region samples the upper blue body above the drawer, so it follows the bubble even if its text changes. The drawer template tracks its first visible handle pose. The colored seat check provides a stronger independent anchor than the motion of the picker as a whole. The receipt template is constrained to its late appearance in the conversation.

The reference movie carries Recreation’s own synthesized mono AAC tones. The final, edited and first-pass pictures are silent. The independent score uses new seeded, 48 kHz stereo procedural effects generated by `synthesize.py`. The measured 5 ms RMS onset and impact markers are separate from WAV placement. The original reference generator and source inventory are retained in the handoff record. Human listening is pending.

## Rebuild

Run from the Sound skill directory with FFmpeg and ffprobe on PATH.

```bash
V=../../../review/imv-v3/sound/recreation
python3 -m recreation.synthesize /tmp/train-assets
for cut in final edited; do
  out="/tmp/train-$cut"
  python3 sound.py mix recreation/train.plan.json "$V/$cut/picture.mp4" "$out"
  python3 sound.py verify recreation/train.plan.json "$V/$cut/picture.mp4" \
    "$out/mix.mp4" "$out/manifest.json"
  python3 -m recreation.render_stems recreation/train.plan.json "$out"
done
```

Preview both MP4s against the soundless pictures. For hands-on edits, import the four WAVs in `cue-stems` at picture zero. The stem command verifies that they sum sample for sample to the generated WAV master. The plan already points to the committed one-shots, and the synthesis command regenerates them into a scratch directory.
