# Agent to Agent — Daniel Tian

Picture samples at 17.50, 18.40, 19.30, 20.20 and 21.55.

- **Before.** The agent phone book visibly finds Lyft, Airbnb and Resy. The audience understands that search returned three names and still needs to see what happened to them.
- **Choice.** The labels fall away while their colored marks remain. The marks move with two others into one avatar cluster. The “Team Offsite, Oct 10” header starts to emerge behind the cluster around 19.87. Muse's first message enters below it.
- **After.** The audience can infer the found agents are now participants in a specific conversation. The surviving marks carry that relation from one screen state to the next.
- **Intent guess.** The motion expresses a membership change and keeps cast recognition intact through the switch.
- **Alternative.** Hard cut from search to a crowded conversation with unfamiliar avatars. The dialogue might eventually explain whose thread it is, with work transferred from the transition to the viewer.
- **Change for Direction.** When a proof involves multiple actors, assign every visible action and reaction to an identifiable actor. Carry a role cue across state changes when identity otherwise becomes ambiguous.
