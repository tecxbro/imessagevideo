# Motion source inventory

Motion reads source frames, borrows the editable mechanism when available, and supplies new preview content. A filmed effect, an authored adaptation, and a teammate's new-scene render are distinct pieces of evidence. Count the same mechanism once even if several sources demonstrate it. An exact filmed range describes the observed run, including any hold. For authored software references without a movie timebase, cite the source component or fixture and record the new preview's frame range separately.

## Baseline play and measurement

`python3 tools/sync_library.py` passed offline against 12 archives, 78 parts, two snapshots and 14,161 extracted files. `node skill/imessage-motion-recreation/director/test_toolkit.mjs` passed its 38 checks.

The six accepted GSAP silent masters fully decoded for 7,499 frames total. In the order listed above, FFprobe counted 655, 1,360, 1,260, 1,283, 1,458 and 1,483 frames at each master's native cadence. The source contact sheets inspected here cover every frame of the three older measured windows (Linq 1091–1111, Photon Mini 211–240 and Gallery 603–653), plus every fourth frame of AffordiHome 216–292.

A fresh render of `director/examples/scenes/mini-app-expand.json` exercised the same editable scene through all five existing adapters. Each produced 120 decodable H.264 frames at 960 × 540, 30 fps. The Pillow contact sheet sampled frames 0, 22, 28, 35, 41, 72, 77, 82, 94 and 119. The card grows in the transcript while the phone header, preceding bubble and composer stay in place. The base starter is an authored card expansion and is distinct from the measured bottom-sheet source.

Run from the repository root with the engine dependencies installed as described in [Running](../RUNNING.md). Use an installed Chromium for the browser adapters and a Python environment with the engine requirements.

```bash
skill=skill/imessage-motion-recreation
scene="$skill/director/examples/scenes/mini-app-expand.json"
out=$(mktemp -d)
for method in html gsap remotion; do
  node "$skill/scripts/engines/render.mjs" --method "$method" --scene "$scene" --out "$out/$method.mp4"
done
node "$skill/scripts/engines/render_motion_canvas.mjs" --scene "$scene" --out "$out/motion-canvas.mp4"
python "$skill/scripts/engines/render_pillow.py" --scene "$scene" --out "$out/pillow.mp4"
for file in "$out"/*.mp4; do
  ffprobe -v error -count_frames -select_streams v:0 \
    -show_entries stream=codec_name,width,height,r_frame_rate,nb_read_frames -of csv=p=0 "$file"
  ffmpeg -hide_banner -loglevel error -i "$file" -map 0:v:0 -f null -
done
```

The historical selector matched “Move the photos beneath a fixed heading.” It returned ambiguous for the reversed actor request, explicit negation and “Give the pictures a sideways glide and leave the title where it is.” It returned no match for a reading hold. Keep these as comparison cases when assessing the new selector's actor assignment and hold decision.
