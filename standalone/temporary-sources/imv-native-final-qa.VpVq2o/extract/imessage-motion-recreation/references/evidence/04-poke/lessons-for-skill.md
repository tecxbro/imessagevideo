# Source04 measured reconstruction lessons

Use `steps-rebuild.md` as the chronological action and failure ledger. Keep baseline and final snapshots immutable, with scene hashes and actual frame intervals. Preserve source and candidate frame indices; a rounded seek label can select a neighboring frame during a fast dismissal.

The production loop was acquisition → native frame/contact-sheet analysis → independent native scene → render → source comparison → diagnose by region → measured correction → bounded cache patch → encoded-file verification. Remotion and GSAP received the same editable geometry and temporal evidence, but use independent render adapters. Alternate native engines receive the same immutable revision and exact changed intervals.

For typography, measure ink rather than font advances. Record both reference and candidate glyph bounds at an exact presentation frame. Fit text using the current local and parent transforms; otherwise a second fit can reset a prior correction. Require explicit input/output paths and refuse to overwrite frozen reports. `measure_label_fit.py` demonstrates that guard.

Ink density is insufficient to identify a font. In the28s distance bubble, Text Semibold matched dark-pixel count but its glyph structure increased spatial error. Comparing eight official SF Pro family/weight variants at identical native ink bounds identified Display Regular instead. `rank_glyph_shapes.py` reproduces that diagnostic, followed by actual browser rendering and `v7-native-ink-fit.json`. Keep family selection component-specific: the map subtitle matched Text Regular, while the title and audio caption matched Display Medium.

When a scene still differs, attribute error to non-overlapping regions before changing a camera. At28s, the bezel, map/distance, audio, keyboard and composer each contributed measurable error. The composer and keyboard had incorrectly inherited a conversation pan; fixing their own layout and key geometry reduced error without moving the audio camera. Native traced bubble silhouettes and44editable waveform rectangles corrected static geometry. Authentic narrow device hardware crops and a map-artwork crop were allowed; all screen UI remains native, and complete source-frame/video overlays are prohibited.

For interrupted renders, verify the contiguous PNG prefix and resume only missing ranges. Use atomic writes and a complete-cache gate before encoding. Never mutate a cache while an encoder is reading it. Preserve prior MP4s, sidecars and QA reports, then patch exact inclusive frame intervals. Validate actual delivered cadence, dimensions, duration and frame count with ffprobe.

Run source and cross-engine QA on the final encoded files after the final patch. Include foreground metrics, native image pairs and explicit residuals; agreement on a white background or a few local ink boxes does not certify1:1 fidelity.

Every-frame peak review is mandatory after held-frame similarity. In Poke, a43sample review looked acceptable but a1283frame scan exposed missing alternating grid stagger, the wrong inbox cut, a two-frame late outro, early option-state timing, independent phone/UI cameras and an occluded first audio frame. Preserve exact original frame IDs, actual rational cadence and every prior revision's evidence before patching.

A measured component classifier is evidence, not ground truth. Reject impossible FFTNCC>1 and zero-energy windows; don't infer a translucent card top from absolute white245. Use local contrast above the measured border. Audit color masks at optical overlaps: Source800/801 audio connected to the keyboard mask, creating a false696px top; the real keyboard held at871. A full text height can change through rasterization while its width and line-to-line spacing reveal a stable camera. Different photo, header, row, hardware, keyboard and suggestion cameras must be measured separately.

Native material can be fitted analytically. At Source800, the observed composer-over-audio RGB establishes0.755opacity for a(243,242,245)material over(153,160,172)audio. Its rect bounds move independently from its text. Trace the measured editable controls and masks; crop only genuine contact artwork, maps/logos and hardware, keeping source screens transparent. Validate individual glyph ink bounds in the actual production runtime, not only font advance widths or Pillow density.

For all render methods, freeze one canonical scene path with byte-identical copied dependencies, a sceneSHA256 and asset manifest. Use that SAME path/hash for every adapter; rebasing paths for equivalent assets changes the manifest hash and obscures provenance. Keep complete frame caches, patch only verified changed ranges, then re-encode and scan every native frame. A low numeric score does not certify1:1 perfection; inspect the ranked native source/candidate/diff panels and document the remaining regions.

- A correct measured pose can still be invisible because of a stale layer start/end. Verify actual source first-visible/cut frames independently of geometric fitting.
- The schema holds the first keyframe backward. An initial nonzero blur/opacity/transform can contaminate an earlier scene; encode the preceding state explicitly.
- Censored edges are observations, not complete geometry: top-clipped titles, composer-occluded map pins and fading gray silhouettes require an uncensored width, a known aspect or another independent anchor.
- Hardware probes must exclude dark UI controls. AtPoke457the composer-plus crossed the bezel probe row and caused a false physical-camera jump.
- When two columns overlap in a transition, calibrate component identities at a later unambiguous pose. Independent outgoing/incoming trajectories cannot be fixed by translating the whole stage.
- For textured logo morphs, preserve genuine material while tracing editable symbol/silhouette geometry. Crossfading two whole logos creates doubled limbs and lighter material even if their centers match.
- Measure opacity from flat material planes, not antialiased glyph edges. Three independent gray planes can recover a shared fade while body widths recover its centered zoom.

- Whole-frame averages can hide a missing pale card. After every full scan, inspect the actual source/candidate panels: Poke526missed an entire map atMAE8.9, and897premature opacity was only6.8.
- Keep exact layer visibility gates separate from fitted geometry. A start rounded to12.65can hide the native375–379entry even when all those poses already exist.
- Low-contrast birth precedes measurable gray body. Confirm coherent original icon/word pixels, normalize opacity to the real held glyph core, and label the first gray-body frame separately.
- Never extrapolate an early photo-camera correction across unmeasured clipped/faded phases. Preserve passing intervals and put explicit restoration anchors before freezing.
- Freeze expensive image measurements into immutable component ledgers. Authoring rebuilds should apply measured state, not refit against mutable production caches.
- A partially censored hardware edge remains visible after a two-edge detector fails. Use an independent surviving edge and measured center until the actual source cut.
- Native text ink probes must exclude overlapping photos and underlying captions. When isolation is uncertain, render the single editable component on a clean diagnostic background instead of fitting a mixed ROI.

V12 additions: Compare Text versus Display optical families spatially, not by ink count or font advance. A faithful source may use Text for inbox rows, Display Semibold for feature headings, Display Regular for body, and Display Medium for a prompt. Normalize source ink to compare glyph structure, then fit actual browser ink independently; Pillow advance is not browser ink. A comma omitted from a ranking input can falsely implicate rasterization even when authored copy is correct. Isolate glyph ROIs from chevrons/physical rails and reject implausible fit scales before applying them. For device sides, outer chrome and inner opening are distinct black runs; fit each physical rail's camera independently and mask its screen transparent. A genuine alternate portrait pose may still be worse than the original expression; retain a rejected variant as evidence rather than merging a small local gain that loses to the current candidate. Scrim/layer order is a separate source of color error from opacity and font weight.

V13 additions: Verify clip-coordinate ownership on positioned images. A parent-space rounded rectangle applied to an image-local clip can expose a flat backing along a straight seam even though every coordinate seems individually plausible; wrap the positioned image in the clipped parent instead. After fixing that bug, fit genuine material identity/timing independently from silhouette morph: a source may switch texture at one native frame while shape continues changing. When two neighboring service logos share broad shapes/colors, independent NCC may accept the wrong actor with a high score; enforce identity/visibility and verify the first coherent source appearance. Badge motion and caption recentering are independent of app-icon motion. Correcting the badge can reveal a caption anchor error that was previously hidden by the wrong badge position. A decisive font audit can also prove the current face correct; retain it instead of forcing every peak into a font explanation.
