# Sidehoe pre-render probes

Each reel is a sequence of selected native frames encoded at 2000 × 2000 at
25 fps using the film's picture settings. Frame maps name the original index
for every reel frame. Side-by-side boards use the decoded reel, with separate
detail crops for the action windows. The source evidence stays outside the
editable project.
