# Instant + New

1. Select **Instant** authoring and **New** presentation from this invocation. Preserve the company, channel and count already supplied. Ask for any missing company or channel before creating a demo.
2. Read [PONY Instant](../pony-demo-instant/SKILL.md) and its [New recipe](../pony-demo-instant/references/new.md). Follow their original referenced skills directly; this entry point does not replace them.
3. Prepare a minimal company brief and run the shared CRM Instant HTML reader/playbook. Do not independently research the company or author replacement copy. Record with local files. Do not start the CRM, read CRM tools, create another Codex/Claude session, queue a worker, or publish/send anything. Use CRM only after an explicit human request.
4. Execute `npm run demo -- instant/new <company-brief-or-result.json> --channel <chosen-channel> --out <fresh-output>/demo.mp4`. For multiple conversations, use the existing sequential local-source batch command.
5. Inspect the video and required review images, then deliver one complete MP4 per requested conversation using absolute file links. Keep encoding, visual review and any separately requested CRM persistence distinct.
