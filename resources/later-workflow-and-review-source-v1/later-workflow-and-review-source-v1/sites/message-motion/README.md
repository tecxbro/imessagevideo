# message studies

Public iMessage motion gallery. Buildless HTML/CSS/JavaScript, 6 films and 30 existing final H.264/AAC MP4 reconstructions. Original videos are included for optional comparison. No video/image regeneration was performed for this site.

The visual direction follows sundays.rsvp's ivory paper, visible column grid, serif type, chrome accents, lime index markers, and compact pill controls. Its proprietary fonts, logo and source code are not reused.

Run `npm run check` for player timing, media path and compatibility checks. No dependency installation or build is required; `dist/` is the deployment output.

Playback uses native video controls and `playsinline`, with optional gesture-driven playback, explicit error reporting and direct MP4 fallback links. Only the selected reconstruction loads; the original loads when comparison is requested. Method switching retains the current time. Rene's source mapping skips its 181 live-action frames. Source audio is muted in comparison to prevent doubled sound.

Registration is stored in `.openai/hosting.json`. The Site was explicitly requested public. The connected Sites helper scripts were not installed or readable in this executor; ordinary Git and an archive of the exact committed static output are used for the equivalent source workflow. Credentials stay in memory and enter the source adapter through hidden stdin.
