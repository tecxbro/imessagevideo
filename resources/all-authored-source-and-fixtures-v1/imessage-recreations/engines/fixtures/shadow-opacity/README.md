# Native shadow before group opacity

The native Motion Canvas Node draws its cached image and its shadow in one Canvas call with the same `globalAlpha`. Canvas blends the shadow and ink separately. At partial opacity, a shadow therefore shows through an otherwise opaque card interior. Source SVG/CSS composites the shadowed opaque component first, then fades that combined result.

The correction uses genuine native Scene2D nodes. Only an authored shadow with `0 < same-node opacity < 1` moves to a native inner Node at opacity1; the existing outer native Node fades the complete result. Opaque nodes retain their original native shadow path. Every no-shadow primitive, authored child, native camera and lifecycle remains intact. No browser/reference scene is flattened.
