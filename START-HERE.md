# iMessage video datasets

Use BUILD-PROMPT.txt for the one-chat project. The six original films are ready to open in originals/. Their original posts, exact GitHub file links, sizes and SHA-256s are the first six rows in video-sources.csv. The originals match the pinned production manifest. The rest of the CSV lists historic media paths, native reference material, motion previews, release examples and the larger launch-film collection. Historical inventory rows can refer to duplicate archive copies.

For the historical checkout, run python3 tools/sync_library.py then python3 tools/library.py verify. Open catalog/index.html for all six originals and the 30 renderer exports. Use inventory/VIDEOS.csv for silent masters and archived duplicates, inventory/AUDIO.csv for effects and stems, inventory/ASSETS.csv for artwork and fonts, and inventory/ANALYSIS.csv for comparisons.

For the Observer release, extract the media ZIP into an empty folder and the skill ZIP into its skill/ subfolder. From the media root run sha256sum -c MEDIA-SHA256SUMS (shasum -a 256 -c MEDIA-SHA256SUMS on macOS).

The public source URLs identify creators. Keep the private production material within the authorized team and check rights before distributing assets or reusing clips in a new film. Separate originals, reference-audio reconstructions, silent masters, derivative previews and authored effects when counting the dataset.
