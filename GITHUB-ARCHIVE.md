## Standalone material

The index branch preserves 20,233 files from 133 source locations. The raw total is 3.75 GiB; duplicate content shares Git objects. It includes editable sources, static assets, fonts, exported videos, audio, measurements, provenance, packaged skills and unique temporary authored source files.

Permanent standalone groups are `sidehoe-recreation`, `sidehoe-skill-trial`, `recreation-evidence`, `v3-prompts`, `real-video-test`, `iv-test`, and `recording-skills`. Temporary authored sources and extracted skill packages are preserved in their own folders.

## Storage, scope, and verification

- Repository visibility remains private.
- The library's existing `STORAGE.json` and `LOCAL-LIBRARY.json` retain hash-verified Git archive parts for oversized original payloads. Existing reconstruction instructions remain with each library branch.
- Dependency installations, Python environments, browser sessions, credential filenames, partial downloads, and regenerable decoded/comparison frame sequences remain local. Temporary render media stays local; temporary authored source is captured. The full inventory records omitted paths and reasons.
- macOS denied access to several protected application-data folders. The inventory records those scan errors. The scan covered accessible user/project folders, hidden skill installations, `/private/tmp`, `/Users/Shared`, `/Volumes`, `/opt`, and `/usr/local/share`, while pruning installed dependencies, caches, app bundles, and chat/memory stores.
- Captured content is checked against credential patterns and the recorded exact source-exclusion hashes. Each written Git blob and final tree is checked against its captured bytes; each published branch is checked against GitHub's reported commit ID.
- Archived fidelity reports retain their original findings and limitations. This archive operation does not perform new rendering or change those verdicts.
- No local source, export, uncommitted work, or regenerable file was deleted.

Archive utilities are included in `archive-tools/`. Their discovery/plan inputs were generated for this machine and date; inventory.json is the durable record.

The final name-based sweep added 20 older/extracted skill copies under `standalone/additional-skill-copies`, preserving each original directory hierarchy.

A separately packaged motion skill found inside the codex-ui build cache is preserved under `standalone/cached-skill-packages`; the complete package is retained even though its parent is a cache.
