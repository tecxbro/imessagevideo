# Working in this video library

Start with `FINAL-PRODUCTION.md`, `PROJECT-HANDOFF.md`, `skill/imessage-motion-recreation/SKILL.md` and `LOCAL-LIBRARY.json`.
The complete projects, movies, source clips, fonts, audio and evidence are in
this checkout after `python3 tools/sync_library.py` finishes. Use the local files first. Drive
IDs retained in historical manifests are recovery provenance, not a normal-use
dependency. Never claim an unsynchronized checkout has the complete archive/oversized scene payloads.

Use `python3 tools/library.py list`, `where 04-poke`, `find QUERY`, or `verify`.
Open `catalog/index.html` for local films/full code and `inventory/index.html`
or `inventory/ALL-FILES.csv` for every payload file location.

For a new company, research from supplied/local evidence first and use online
primary sources when needed. Inspect actual atlas images and source frames;
choose motion, editable component boundaries, shot timing and UI sound before
rendering. Generic starters are authored examples; accepted scenes are measured
full films. Keep their distinction and known fidelity/editability limits clear.

The five completed adapters are Remotion, GSAP, HTML/SVG, native Motion Canvas
and Pillow with FFmpeg. Figma is an unvalidated prototype. Dependency locks and
setup instructions are included; third-party dependency installations and browser
binaries are environment setup, not authored source included by this repository.

Preserve frozen archives and accepted results. Write new work to a fresh working
folder. Log the observed failure and changed variable before retrying. Retain
source/license provenance; keep this repository private unless the user changes
its intended audience explicitly. Never commit credentials, session download
URLs, installed dependencies or generated caches.
